# SignalKit — установка с нуля

Пошаговая инструкция: свой Telegram-канал + свой терминал MT5.

---

## 1. Установить ПО

1. **Python 3.10+** — https://www.python.org/downloads/  
   Обязательно: ☑ *Add python.exe to PATH*
2. **MetaTrader 5** вашего брокера — установить и один раз войти в счёт (хотя бы демо)

Проверка Python в cmd:

```bat
python --version
```

---

## 2. Скачать SignalKit

- Клонировать: `git clone <url-репозитория>`
- Или скачать ZIP → «Code → Download ZIP» → распаковать

Откройте папку проекта (там должен быть `START.bat`).

---

## 3. Первый запуск панели

Дважды щёлкните **`START.bat`**.

Что произойдёт:
- при необходимости установятся пакеты из `requirements.txt`
- создастся `НАСТРОЙКИ.ini` из примера
- откроется браузер: http://127.0.0.1:8765/

Чёрное окно bat **не закрывайте** — это движок.

Строка «Движок подключен» = всё ок.

---

## 4. Подключить Telegram-канал

### 4.1. Имя канала

В панели поле **Канал**, например:

```
my_signals_channel
```

без `https://t.me/` и без лишних пробелов.

### 4.2. Режим загрузки

| Режим | Когда | Что нужно |
|--------|--------|-----------|
| `web` | быстрый тест, свежие посты | только имя публичного канала |
| `telethon` | история за месяцы/год | api_id, api_hash, phone |

Для telethon:
1. Откройте https://my.telegram.org → войдите → **API development tools**
2. Создайте приложение, скопируйте **api_id** и **api_hash**
3. В панели укажите телефон в формате `+79001234567`
4. Сохраните → «Отправить код» → введите код из приложения Telegram

Сессия сохранится в `tg_session.session` (в git не попадает).

---

## 5. Научить парсер вашему формату постов

Скопируйте один реальный пост канала и сопоставьте поля:

### Вариант A — подписи (labels)

```
#EURUSD
Тип сделки: Лимитный ордер на покупку
Цена открытия: 1.08500
Стоп лосс: 1.08000
Тейк профит: Открытый
```

В настройках:
- format = `labels`
- label_side / label_entry / label_sl / label_tp — как в посте
- buy_words / sell_words — корни слов на языке канала

### Вариант B — одна строка (compact)

```
#eurusd EUR/USD H1 Buy 1.0850 SL 1.0800 TP 1.0950
```

- format = `compact`
- можно применить пресет **AMarkets** и поправить под себя

### Сопровождение (manage)

Если канал пишет «стоп на точку входа», «лимитку удаляем», «меняем цену открытия» — оставьте:

```
[manage]
enabled=yes
```

и при необходимости поправьте словари слов под формулировки автора.

Нажмите **Сохранить**.

---

## 6. Робот №1 — анализ истории

1. Укажите `days_back` (например 30 или 365)
2. **«1. Скачать сигналы»**
3. Откройте страницу `/signals` — проверьте, что сделки разбираются
4. Запустите MT5 и войдите в счёт
5. **«2. Анализ сделок»**
6. Смотрите отчёт `/report`

Если `parsed=0` — неверные подписи: сравните с текстом поста.

---

## 7. Робот №2 — Live в MT5

1. В панели: **«3. Подготовить Live»**  
   (скопирует EA в Experts и правила в Common\Files\SignalKit)
2. В MT5:
   - Сервис → Настройки → Советники  
   - ☑ Разрешить алгоритмическую торговлю  
   - ☑ Разрешить WebRequest для: `https://t.me`
3. MetaEditor → открыть `TG_Signal_Live_EA.mq5` → Compile (F7)
4. Navigator → Experts → Refresh → перетащить на график
5. Параметры:
   - `InpDryRun = true` (сначала только лог!)
   - канал подтянется из `parse_rules.txt`
6. Включить AutoTrading
7. Journal: `Bootstrap OK` → ждёт новые посты
8. Когда всё проверено: `InpDryRun = false` (лучше на демо)

Live использует **публичную** ленту `t.me/s/<channel>` (WebRequest).  
Полная история через Telethon — только для анализа в панели.

---

## 8. Другой терминал / другой брокер

- Установите MT5 другого брокера
- Снова нажмите **«3. Подготовить Live»** (EA скопируется во все найденные терминалы)
- Или вручную скопируйте `MT5/TG_Signal_Live_EA.mq5` в  
  `...\MetaTrader 5\MQL5\Experts\`
- Суффиксы символов брокера: в EA `InpSymbolSuffix` / `InpAutoResolve`

Бэктест читает котировки из **того MT5, который сейчас запущен и залогинен**.

---

## 9. Другой Telegram-канал

1. Смените `channel` в панели
2. Подправьте правила разбора под формат постов
3. Сохраните
4. Снова «Скачать сигналы» и «Подготовить Live» (обновит parse_rules.txt)

Можно держать несколько копий папки SignalKit с разными `НАСТРОЙКИ.ini`.

---

## Частые проблемы

| Проблема | Что сделать |
|----------|-------------|
| Python не найден | Переустановить Python с PATH, перезапустить ПК |
| Движок не подключен | Запущен ли START.bat? Открыт ли :8765? |
| Нет кода Telegram | Смотрите чат «Telegram» в приложении, не SMS |
| WebRequest fail | Добавьте `https://t.me` в список URL MT5 |
| parsed=0 | Неверные label_* / format / must_contain |
| Бэктест NO_DATA | MT5 открыт? Есть история по символу? |
| Live молчит | DryRun/Journal, канал публичный? Bootstrap прошёл? |
