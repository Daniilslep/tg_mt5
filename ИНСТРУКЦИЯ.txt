ЧТО НУЖНО УСТАНОВИТЬ ОДИН РАЗ
-----------------------------
1) Python 3: https://www.python.org/downloads/
   Важно: галочка «Add python.exe to PATH».
2) MetaTrader 5 вашего брокера (для анализа и live).

КАК ОТКРЫТЬ ПАНЕЛЬ (ВАЖНО)
-------------------------
Запускайте файл с английским именем (самый надёжный способ):

    START.bat

Он:
  • включает движок (чёрное окно — не закрывать)
  • через 2 секунды сам открывает браузер: http://127.0.0.1:8765/

Также можно: Открыть_панель.bat (он просто вызывает START.bat).

Если браузер сам не открылся — откройте вручную:
    http://127.0.0.1:8765/

Зелёная строка «Движок подключен» = всё ок.

Файл panel.html / Панель.html — сама страница.
Без запущенного START.bat кнопки работать не будут.


ВСЁ НАСТРАИВАЕТСЯ В ОДНОМ МЕСТЕ
------------------------------
Файл:  НАСТРОЙКИ.ini
   (если его нет — появится сам при первом запуске панели)

Или удобнее: поля прямо в HTML-панели → кнопка «Сохранить».


КАКИЕ ДАННЫЕ НУЖНЫ (и какие НЕ нужны)
-------------------------------------
Нужны:
  • Имя Telegram-канала (например tradingplusforex)
  • Как устроен пост: подписи «Цена открытия», «Стоп лосс» и т.д.
    (или нажмите готовый шаблон TradingPlus / AMarkets)

Для длинной истории (год) дополнительно:
  • api_id и api_hash — https://my.telegram.org → API development tools
  • phone — ваш номер Telegram в формате +7900…

НЕ нужны для этой системы:
  • Bot token
  • Your ID / Current chat ID
  (они нужны только ботам-уведомлениям; мы их не используем)


РОБОТ №1 — АНАЛИЗ ИСТОРИИ
-------------------------
1. Дважды щёлкните:  Открыть_панель.bat
2. Укажите канал и шаблон разбора сообщений → «Сохранить»
3. Если период большой — заполните api_id / api_hash / phone
4. Нажмите «1. Скачать сигналы»
   (при первом telethon Telegram пришлёт код — введите в чёрном окне bat)
5. Откройте MetaTrader 5 и войдите в счёт
   Важно для M1 за год: Сервис → Настройки → Графики →
   «Макс. баров в истории» = Unlimited → OK → полностью перезапустите MT5.
   (Иначе анализ возьмёт только ~3 месяца M1, остальное уйдёт в H1.)
6. Нажмите «2. Анализ сделок»
7. Смотрите отчёт кнопкой «Открыть отчёт анализа»

Как объяснить парсеру «какие посты брать»:
  • «Обязательные слова» — пост должен их содержать (напр. Стоп лосс)
  • «Пропускать, если есть» — фиксации, перенос стопа и т.п.
  • Подписи полей — как написано у автора канала
  • Если TP «Открытый» — цель считается как RR × риск (по умолчанию 2)


РОБОТ №2 — LIVE В РЕАЛЬНОМ ВРЕМЕНИ (через MT5)
----------------------------------------------
1. В панели нажмите «3. Подготовить Live»
   (скопирует советник и правила разбора)
2. В MT5:
   Сервис → Настройки → Советники
     ☑ Разрешить алгоритмическую торговлю
     ☑ Разрешить WebRequest → добавьте строку:  https://t.me
3. Navigator → Experts → обновить (F5) → TG_Signal_Live_EA
4. Перетащите на любой график
5. Сначала: InpDryRun = true  (только лог, без реальных ордеров)
6. AutoTrading — включить
7. Journal: Bootstrap OK … Waiting for NEW posts
8. Когда всё ок — InpDryRun = false (лучше сначала демо-счёт)


ГОТОВЫЕ ШАБЛОНЫ КАНАЛОВ
-----------------------
В панели кнопки:
  • TradingPlus — русские подписи (Тип сделки / Цена открытия / Стоп лосс)
  • AMarkets — компактная строка (#eurusd H1 Buy … SL … TP …)

Для своего канала: скопируйте один пост автора и пропишите те же
подписи в поля панели.

ЧАСТЫЕ ПРОБЛЕМЫ
---------------
• «Python не найден» → установите Python с галочкой PATH, перезапустите ПК
• WebRequest запрещён → добавьте https://t.me и перезапустите MT5
• parsed=0 → неверные подписи полей; сравните с текстом поста / смените пресет
• Для года мало сигналов в web-режиме → поставьте fetch_mode=telethon
