Краткая инструкция на русском. Полная пошаговая установка: SETUP.md

1) Установите Python 3 (Add to PATH) и MetaTrader 5
2) Запустите START.bat → откроется http://127.0.0.1:8765/
3) Заполните канал и правила разбора → Сохранить
4) Для длинной истории: api_id / api_hash с my.telegram.org + phone → вход по коду
5) «1. Скачать сигналы» → «2. Анализ сделок» (MT5 должен быть открыт)
6) «3. Подготовить Live» → в MT5 разрешите WebRequest https://t.me
7) Скомпилируйте TG_Signal_Live_EA, DryRun=true, затем демо

Настройки: НАСТРОЙКИ.ini (создаётся из НАСТРОЙКИ.пример.ini)
Секреты и сессии в git не коммитьте (.gitignore уже настроен).
