# Параметры Live-робота `TG_Signal_Live_EA`

Советник читает **публичную** ленту Telegram (`t.me/s/<канал>`) и открывает/сопровождает сделки в MT5.

Кнопка панели **«3. Подготовить Live»**:
1. копирует `MT5/TG_Signal_Live_EA.mq5` в Experts найденных терминалов;
2. пишет правила разбора в `Common\Files\SignalKit\parse_rules.txt` из текущих настроек панели / `НАСТРОЙКИ.ini`.

Перед работой в MT5: разрешите алготорговлю и WebRequest для `https://t.me`.

---

## Как задаются правила

| Источник | Когда используется |
|----------|-------------------|
| `parse_rules.txt` | если `InpLoadRulesFile = true` (по умолчанию) — **рекомендуется** |
| Inputs советника | если файла нет или `InpLoadRulesFile = false` |

После смены канала/слов в панели снова нажмите **«3. Подготовить Live»**, затем перезапустите EA на графике (или смените таймфрейм), чтобы перечитать файл.

---

## Группа «Telegram»

| Параметр | По умолчанию | Что делает |
|----------|--------------|------------|
| **InpChannel** | пусто / из файла | Имя канала без `https://t.me/` и без лишних пробелов. При `InpLoadRulesFile=true` обычно берётся из `parse_rules.txt`. |
| **InpPollSeconds** | `10` | Как часто (сек) опрашивать ленту Telegram. Минимум в коде ≈ 5 с. |
| **InpIgnoreHistory** | `true` | При первом запуске **не торговать** старые посты ленты: запомнить максимальный id и ждать только новые. `false` — попытается обработать видимую историю (опасно на реале). |
| **InpMaxSignalAgeSec** | `3600` | Максимальный возраст сигнала в секундах. Старше — пропуск. `0` — не ограничивать по возрасту. |
| **InpLoadRulesFile** | `true` | Читать `SignalKit\parse_rules.txt` из Common Files. Оставьте `true`, если пользуетесь панелью. |

---

## Группа «Разбор поста (если нет файла)»

Используются, когда файла правил нет или отдельные ключи в файле пустые. При нормальной работе панели достаточно настроить разбор **в панели**, а не в inputs.

| Параметр | По умолчанию | Что делает |
|----------|--------------|------------|
| **InpFormat** | `labels` | `labels` — поля с подписями («Стоп лосс: …»). `compact` — одна строка (`Buy … SL … TP …`). |
| **InpMustContain** | `Стоп лосс` | Пост должен содержать хотя бы одно из слов (через `\|`). Иначе вход не разбирается. |
| **InpSkipContains** | фикс./стоп/… | Если в посте есть эти слова — **пропустить** как сигнал входа (при выключенном manage из файла логика может отличаться). Лучше держать пустым, если сопровождение включено в `parse_rules.txt`. |
| **InpLabelSide** | `Тип сделки` | Подпись поля направления/типа ордера. |
| **InpLabelEntry** | `Цена открытия` | Подпись цены входа. |
| **InpLabelSL** | `Стоп лосс` | Подпись стопа. |
| **InpLabelTP** | `Тейк профит` | Подпись тейка. |
| **InpBuyWords** | `покуп\|лонг\|…` | Корни слов «покупка» (через `\|`). |
| **InpSellWords** | `продаж\|шорт\|…` | Корни слов «продажа». |
| **InpLimitWords** | `лимит\|limit` | Если есть — ордер считается лимитным. |
| **InpTpOpenWords** | `открыт` | Если TP «открытый» — цель = вход ± `InpOpenTpRR` × риск до стопа. |
| **InpOpenTpRR** | `2.0` | RR для синтетического TP при «открытом» тейке. |
| **InpCompactBuy / Sell / SL / TP** | `Buy` / `Sell` / `SL` / `TP` | Маркеры для `format=compact`. |
| **InpManageEnabled** | `true` | Сопровождение цепочек (BE, смена стопа, снятие лимита, закрытие и т.д.). В файле правил может быть уточнено. |
| **InpInheritWords** | `не меняем\|…` | Пост «параметры не меняем» — взять SL/TP с уже открытой позиции/лимита. |
| **InpLevelsWords** | `меняем цену\|…` | Пост о смене цены входа / перестановке лимита. |

Слова cancel / reverse / close / modify_sl / to_market и др. при старте задаются дефолтами в коде и **перезаписываются из `parse_rules.txt`**, если панель их выгрузила. Править их удобнее в панели SignalKit, а не в inputs EA.

## Группа «Торговля»

| Параметр | По умолчанию | Что делает |
|----------|--------------|------------|
| **InpFixedLot** | `0.01` | Фиксированный лот, если риск-процент выключен. |
| **InpRiskPercent** | `0` | Риск на сделку в % от equity. `0` = только `InpFixedLot`. При >0 лот считается от дистанции до стопа. |
| **InpAllowLimit** | `true` | Разрешить лимитные ордера. `false` — лимитные идеи открывать рынком (если логика дойдёт до входа). |
| **InpSlippagePoints** | `50` | Максимальное проскальзывание в пунктах терминала. |
| **InpMagic** | `26080299` | Magic-номер ордеров EA. Меняйте, если несколько копий EA на одном счёте. |
| **InpCommentPrefix** | `SK#` | Префикс комментария (`SK#12345` = id поста). Нужен, чтобы находить «свою» сделку в цепочке. |
| **InpSkipBadDirection** | `true` | Не открывать, если уровни противоречат стороне (например buy со стопом выше входа). |
| **InpMaxStopAdjustPts** | `80` | На сколько пунктов можно «дотянуть» стоп/вход до минимальной дистанции брокера (StopsLevel). |
| **InpDryRun** | `true` | **Режим без реальных ордеров**: только Journal. Всегда начинайте с `true`, потом демо, потом реал. |

## Группа «Символы / лог»

| Параметр | По умолчанию | Что делает |
|----------|--------------|------------|
| **InpOnlySymbols** | пусто | Белый список символов через запятую (`EURUSD,GBPUSD`). Пусто = все, что пришло из канала. |
| **InpSymbolSuffix** | пусто | Суффикс брокера (`m`, `.pro` и т.п.). Добавляется к имени из поста. |
| **InpAutoResolve** | `true` | Автоподбор символа в Market Watch (с суффиксом / без / верхний регистр). |
| **InpUseCommonFolder** | `true` | Читать/писать файлы в **Common\Files** (нужно для `parse_rules.txt` от панели). |
| **InpVerboseParse** | `false` | Подробный лог разбора постов в Journal (для отладки). |

---

## Рекомендуемый порядок

1. Панель → сохранить настройки канала → **«3. Подготовить Live»**
2. MT5: WebRequest `https://t.me`, алготорговля
3. Compile `TG_Signal_Live_EA` → на график
4. **`InpDryRun = true`**, `InpLoadRulesFile = true`
5. Journal: `Bootstrap OK` → дождаться нового поста канала
6. Проверить лог DRY-RUN → на демо `InpDryRun = false`

## Частые вопросы

**Канал в inputs пустой, а EA работает?**  
Да: канал берётся из `parse_rules.txt`.

**Сменил слова в панели — Live не изменился?**  
Снова «Подготовить Live» и перезапуск EA.

**Два терминала / два брокера?**  
Снова «Подготовить Live» (копия EA во все найденные) или укажите `InpSymbolSuffix` / `InpAutoResolve` под символы брокера.

**Live ≠ бэктест 1 в 1**  
Live видит только свежую публичную ленту; бэктест — полную историю Telethon + M1 терминала.

**Пост с картинкой не открылся?**  
На `t.me/s/` у части постов нет текста (`text_not_supported`). С EA **v1.21** текст добирается из `og:description` страницы поста. Перекомпилируйте советник.  
Если EA запустили *после* сигнала при `InpIgnoreHistory=true`, этот пост уже считается «историей» и не торгуется — ждите следующий или временно `InpIgnoreHistory=false` (осторожно).
