# SignalKit

Telegram → MetaTrader 5: разбор сигналов канала, бэктест и live-торговля.

Два режима:
1. **Анализ истории** — скачать посты канала, разобрать сделки, прогнать по котировкам MT5
2. **Live** — советник MT5 читает публичную ленту Telegram и сопровождает сделки (цепочки сообщений)

Работает с **любым** публичным (или доступным вам) каналом: правила разбора задаются в `НАСТРОЙКИ.ini` / панели.

---

## Требования

- Windows
- [Python 3.10+](https://www.python.org/downloads/) (галочка **Add python.exe to PATH**)
- [MetaTrader 5](https://www.metatrader5.com/) брокера (для бэктеста и live)
- Для полной истории канала: аккаунт Telegram + `api_id` / `api_hash` с [my.telegram.org](https://my.telegram.org)

---

## Быстрый старт

```bat
1. Распакуйте / клонируйте репозиторий
2. Дважды щёлкните START.bat
3. Откроется http://127.0.0.1:8765/
4. Заполните канал и правила → «Сохранить»
5. «1. Скачать сигналы» → «2. Анализ сделок» → «3. Подготовить Live»
```

Подробно: **[SETUP.md](SETUP.md)** (пошагово с нуля).

Панель: настройки разбиты на группы (фильтр постов, подписи, buy/sell/TP, цепочки, закрытие, SL/TP, лимиты, разворот).  
Отчёты `/signals` и `/report` можно скачать как **HTML**.  
Бэктест на **M1**: при нехватке баров в API подтягивается история из `.hcc` терминала; в MT5 поставьте макс. баров = **Unlimited**.

## Что не попадает в Git

Секреты и мусор уже в `.gitignore`:

| Не коммитить | Зачем |
|---|---|
| `НАСТРОЙКИ.ini` | ваши api_id, phone, канал |
| `*.session` | сессия Telegram |
| `output/` | скачанные сигналы и отчёты |
| `.venv/` | виртуальное окружение |

В репозитории лежит только **`НАСТРОЙКИ.пример.ini`**. При первом `START.bat` он копируется в `НАСТРОЙКИ.ini`.

## Настройка под свой канал

1. Скопируйте один типичный пост автора
2. В панели укажите:
   - **channel** — имя без `https://t.me/`
   - **format** — `labels` (поля с подписями) или `compact` (одна строка)
   - подписи: Тип сделки / Цена открытия / Стоп / Тейк — как у автора
   - слова Buy/Sell на языке канала
3. Включите **manage**, если канал шлёт сопровождение («стоп на вход», «лимитку удаляем», «меняем цену…»)
4. Сохраните → скачайте сигналы → проверьте `/signals`

Готовые примеры правил: `presets/tradingplus.ini` (labels), `presets/amarkets.ini` (compact).

## Live в MT5

1. В панели: **«3. Подготовить Live»**
2. MT5 → Сервис → Настройки → Советники:
   - разрешить алготорговлю
   - WebRequest: добавить `https://t.me`
3. Скомпилировать `TG_Signal_Live_EA.mq5`, повесить на график
4. Сначала **`InpDryRun = true`**, потом демо, потом реал

Правила подхватываются из `Common\Files\SignalKit\parse_rules.txt`.  
**Все параметры EA с пояснениями:** [LIVE_EA.md](LIVE_EA.md)

## Безопасность

- Не публикуйте `НАСТРОЙКИ.ini`, `.session`, логи с телефонами
- Live по умолчанию в dry-run
- `api_id` / `api_hash` — личные ключи приложения Telegram, не bot-token
